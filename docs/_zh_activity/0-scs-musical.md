*2023年春季*，我组织并导演了 **The SCS Musical**：一场由CMU计算机学院（SCS）研究生自编自演、也献给研究生们的音乐剧串烧，共有30多位演员参演，吸引了200多名观众。

<!--more-->

这是一个关于研究生生活的演出之夜，也正如海报上写的，为SCS的研究生们送上一点“情感伤害（DAMAGE）支持”。作为导演（同时也是演员），我召集了来自SCS各个系的演员，协调排练，最终把整场演出搬上了舞台。协调一场大型演出、一个大团队，再加上各种媒体技术，真的很有意思。
